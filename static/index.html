About This Game

A decaying Victorian mansion drowns in eternal twilight, its corridors alive with secrets and shadows that remember what you've forgotten.

AI Techniques:

  • NPC Memory (RAG): NPCs remember past conversations and facts about you using vector embeddings.
  • Emotional State: Each NPC tracks mood and fear, dynamically changing their behavior and dialogue.
  • Intelligent Shop: Merchants use agentic tool-calling to process real transactions in character.
  • Web Search: The Oracle can search the internet in real-time to answer questions about the outside world.
  • Natural Language Commands: All interactions are parsed and understood through GPT, not keyword matching.
  • Dynamic Routing: The entire game is a state graph that intelligently routes between exploration, combat, dialogue, and more.
